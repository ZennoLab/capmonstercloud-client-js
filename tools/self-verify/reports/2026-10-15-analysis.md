## Confirmed findings and fixes

- Hunt `metadata.widgetUrl` is already present in this checkout. The matrix now verifies it reaches createTask over HTTP in CJS and ESM. Hunt requires the full widget URL; `data` is a separate solving mode. The runner does not contact the target website.
- Alibaba `punishUrl` and `cookieRequired` are already present, but `sceneId` and `prefix` were unconditionally required in declarations. The punish-only payload could run in JS while failing TypeScript compilation. These fields are now optional; a public type contract compiles the punish-only request and rejects a string cookieRequired.
- Alibaba cookie responses were missing from the SDK response declaration. Added optional `domains` containing domain cookie maps. Documentation provides a cookies-only response example, so `data` is now optional too. This is a type compatibility change: consumers reading `data.tokens` must check `data` first. Local HTTP checks verify cookies survive SDK response handling.
- ESM's createRequire/import.meta workaround was already present. Regression checks now load through the public package export and invoke actual transport in both module formats, rather than bypassing exports with dist paths.
